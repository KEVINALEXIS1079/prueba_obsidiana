# Setup Inicial del Servidor Backend con NestJS

Este Pull Request inicializa y configura el esqueleto del backend utilizando NestJS.

## Cambios Realizados
- Inicialización del framework NestJS en el subdirectorio `backend/`.
- Configuración de dependencias por defecto de npm.
- Exclusión de configuraciones locales de Obsidian en `.gitignore` para evitar filtraciones de tokens.
- Creación de un lienzo (Canvas) de flujo de trabajo en Obsidian.

## Cómo Iniciar el Backend
1. Navegar a la carpeta del backend: `cd backend`
2. Instalar dependencias (si aplica): `npm install`
3. Iniciar en modo desarrollo: `npm run start:dev`
